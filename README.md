# AI Hoop Masters

AI Hoop Masters is an AI-powered basketball coaching app that provides personalized feedback on shooting form. The app processes uploaded videos to generate:
- **Text Feedback**: Actionable insights on shooting form.
- **Audio Feedback**: Verbal coaching instructions.
- **Visual Feedback**: Illustrations of proper shooting techniques.

---

## Features
- **Video Upload**: Analyze basketball shooting videos for form improvement.
- **Text Feedback**: Get detailed analysis and suggestions.
- **Audio Feedback**: Hear personalized instructions.
- **Visual Feedback**: See proper form through AI-generated images.
