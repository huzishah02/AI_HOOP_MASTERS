# AI Hoop Masters

AI Hoop Masters is an AI-powered basketball coaching app that provides personalized feedback on shooting form. The app processes uploaded videos to generate:
- **Text Feedback**: Actionable insights on shooting form.
- **Audio Feedback**: Verbal coaching instructions.
- **Visual Feedback**: Illustrations of proper shooting techniques.

---

## Features
- **Video Upload**: Analyze basketball shooting videos for form improvement.
- **Text Feedback**: Get detailed analysis and suggestions.
- **Audio Feedback**: Hear personalized instructions.
- **Visual Feedback**: See proper form through AI-generated images.

---

## How to Run the App
Prerequisites
Python 3.10 or higher installed on your system.
pip (Python package installer) installed.
Steps to Run the App
Clone the Repository
Clone the project repository from GitHub:
git clone https://github.com/huzishah02/AI_HOOP_MASTERS.git
Navigate to the Project Directory
Change your working directory to the project folder:
cd AI_HOOP_MASTERS
Install Required Dependencies
Install all necessary Python libraries using pip:
pip install -r requirements.txt
Run the Application
Start the Flask application:
python3 AppTest2.py
Open the Application in a Browser
Once the app is running, open a web browser and navigate to:
http://127.0.0.1:8000
Use the App
Upload a basketball shooting video.
Receive visual, audio, and text-based feedback to improve your shooting form.
Troubleshooting

Python Version: Ensure you're using Python 3.10 or higher. Check your version with:
python3 --version
Pip Installation Issues: If pip install fails, upgrade pip with:
python3 -m pip install --upgrade pip
Dependency Issues: Ensure all dependencies in requirements.txt are installed correctly.
